# Izado · app del móvil

Programa instalable (PWA) para registrar accesorios de elevación desde el móvil: altas con foto de la etiqueta, revisiones con fotos de los defectos y movimientos (salida a obra / devolver a nave). Funciona sin cobertura.

- Este repositorio solo lleva el **programa**. No lleva datos de equipos ni de personas.
- Los datos van en `Izado-datos-movil_VN.json`, que Prevención pasa a cada móvil (WhatsApp como Documento, o correo). Nunca se sube aquí.
- Lo hecho en el móvil se manda con **Enviar** (un `.json`) a Prevención, que lo carga en Izado.

Instalar: abrir la dirección de GitHub Pages en Chrome (Android) → menú ⋮ → «Instalar app»; en iPhone, Safari → Compartir → «Añadir a pantalla de inicio».
